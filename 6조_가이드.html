03Kiro 첫 요청 예시

이 프로젝트의 .kiro/steering과 README를 읽고, 로컬 실행 방법과 수정 가능한 파일을 확인해 주세요. 기존 규칙은 유지하고 아직 코드는 수정하지 말아 주세요. 우리 팀 정보 (확인만 하고 지금 서버 작업은 하지 마세요): - 우리는 6조이고, 팀 서버는 52.89.185.105 입니다. - 로컬은 mock AI로 개발하고, 실제 AI 결과는 통합 담당자가 scripts/deploy.ps1로 Check → Deploy 한 뒤 팀 서버에서 확인합니다. - PEM은 프로젝트 바깥 $HOME\hackathon-e4-t06.pem 에 있습니다. 경로만 쓰고 내용은 읽지 마세요. - 파일 저장이 필요하면 S3 버킷 hackathon-e4-t06-data 하나만 씁니다.

04우리 조 서버

공인 IP52.89.185.105 오리건 · us-west-2
접속 키hackathon-e4-t06.pem — 내 사용자 폴더(C:\Users\내 이름)로 옮겨서 씁니다. 프로젝트 안에 넣으면 배포가 거부됩니다.
받은 6조 폴더에서 주소창에 powershell 입력 → 엔터 → 실행
Copy-Item .\hackathon-e4-t06.pem $HOME
처음 한 번 키 권한 정리 (안 하면 bad permissions로 접속이 안 됩니다)
icacls $HOME\hackathon-e4-t06.pem /inheritance:r /grant:r "${env:USERNAME}:R"
처음 한 번 접속ssh -i $HOME\hackathon-e4-t06.pem ubuntu@52.89.185.105 hostname
질문이 나오면 yes 입력. 이걸 안 하면 배포가 Host key verification failed로 멈춥니다.
배포 검사.\scripts\deploy.ps1 -ServerHost 52.89.185.105 -KeyPath $HOME\hackathon-e4-t06.pem -Mode Check
배포.\scripts\deploy.ps1 -ServerHost 52.89.185.105 -KeyPath $HOME\hackathon-e4-t06.pem -Mode Deploy
서버 화면 보기ssh -i $HOME\hackathon-e4-t06.pem -N -L 127.0.0.1:18080:127.0.0.1:8080 ubuntu@52.89.185.105
창을 켜 둔 채 브라우저에서 http://127.0.0.1:18080 → 웹 계정 아이디 team06 (비밀번호는 운영진 안내)
파일 저장소hackathon-e4-t06-data
이 버킷 하나만 씁니다. 안에서 폴더로 나눠 쓰세요 (예: uploads/, data/, outputs/)

키 옮기기 다음 명령들은 Kiro 터미널(템플릿 최상위 폴더)에서 실행합니다. 배포는 조의 통합 담당자 한 명만 합니다.
